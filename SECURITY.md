# Security Policy

## Supported Versions

Currently, the following versions of GeoSense Web are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability in GeoSense Web, please follow these steps:

1.  **Do NOT** open a public issue on GitHub.
2.  Email the project maintainers directly at security@geosense-web.org (placeholder).
3.  Include details about the vulnerability and steps to reproduce it.

We will acknowledge your report within 48 hours and work to provide a fix as soon as possible.

## Security Best Practices for Users

-   Ensure your database credentials are secure and not hardcoded in the application.
-   Use environment variables for sensitive configuration.
-   Regularly update dependencies using `npm audit`.
